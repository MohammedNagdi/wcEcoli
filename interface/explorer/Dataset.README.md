This locally prepared package contains the unchanged HF-06 serving bundle under
`release/`. Its own `release/README.md` describes the scientific contents,
interpretation and limitations. It contains twelve designs, seed 0 for each,
47 actual sequential generation trajectories, scalar channels and four molecular
matrix families. Every saved sample and molecule column is retained.

This work uses the Stanford wcEcoli model. The original license is preserved
verbatim in `LICENSE.md`. The owner has confirmed hosting permission for the
current explorer version using this unchanged release. Additional features must
be communicated first. No broader rights or Stanford endorsement are claimed.
See `PUBLICATION.md`.

This package has not been uploaded. Publication records its immutable commit.
The private Dataset may be read by a public explorer: data exposed by its public
API will be accessible to visitors even though the Dataset repository is private.

Do not edit `release/` independently: its manifest inventories every payload with
size and SHA-256. The manifest does not hash itself. Top-level packaging and
license documents are inventoried separately and count toward the 10 GB total
package ceiling (target below 5 GB). No raw listener output or Parca files are
needed for serving this dataset.
